Semana 1 - Sistemas de Información

¿Qué es un Sistema de Información?

Un sistema de información es un conjunto integrado de elementos (hardware, software, datos, telecomunicaciones y personas) que recoge, procesa, almacena y distribuye información para facilitar la toma de decisiones, mejorar la coordinación y el control, y optimizar las operaciones de una organización. Estos sistemas transforman datos en conocimiento útil para diferentes niveles jerárquicos de una empresa.

Tipos de Sistemas de Información y Ejemplos

1. Sistemas de Procesamiento de Transacciones (TPS)

Función: Registro y procesamiento de transacciones comerciales, como ventas, pagos, inventarios.

Ejemplo: En una agencia de viajes como Despegar, un TPS gestiona la compra de boletos de avión, reservaciones de hoteles y pagos, asegurando que cada transacción quede registrada y disponible en tiempo real.

2. Sistemas de Control de Procesos de Negocio (BPM)

Función: Control y mejora continua de procesos físicos o industriales.

Ejemplo: En una planta de refinación de petróleo, sensores conectados a computadoras monitorean continuamente las reacciones químicas y ajustan variables como temperatura y presión.

3. Sistemas de Colaboración Empresarial o ERP

Función: Soporte a la gestión global y coordinación interdepartamental.

Ejemplo: Un ERP puede coordinar inventarios, finanzas, ventas y producción en una única plataforma.

4. Sistemas de Información Gerencial (MIS)

Función: Análisis y presentación de información para la gestión operativa.

Ejemplo: Reportes mensuales sobre ventas, costos y desempeño financiero.

5. Sistemas de Apoyo a la Toma de Decisiones (DSS)

Función: Soporte en decisiones no rutinarias y tácticas.

Ejemplo: Modelos para proyectar el impacto de cambios en precios o estrategias de marketing.

6. Sistemas de Información Ejecutiva (EIS)

Función: Monitoreo continuo del entorno interno y externo para decisiones estratégicas.

Ejemplo: Dashboard con métricas de rentabilidad, cuota de mercado y satisfacción del cliente.

7. Sistemas de Automatización de Oficinas (OAS)

Función: Soporte a tareas rutinarias y administrativas.

Ejemplo: Correo electrónico, agendas electrónicas, procesamiento de textos y videoconferencias.

8. Sistemas de Trabajo del Conocimiento (STC)

Función: Gestión y producción de conocimiento para usuarios especializados.

Ejemplo: Programas para análisis estadístico, diseño asistido por computadora o sistemas expertos médicos.

Componentes Esenciales de un Sistema de Información

  • Hardware: Equipos físicos como servidores, computadoras, dispositivos de red, sensores y móviles.
  • Software: Programas que ejecutan operaciones de datos, desde sistemas operativos hasta aplicaciones.
  • Datos: Información organizada que alimenta el sistema, almacenada en bases de datos o archivos.
  • Telecomunicaciones: Infraestructura que permite la transmisión de datos entre componentes.
  • Personas: Usuarios que emplean el sistema, desde operadores hasta altos ejecutivos.
