Semana 2 - Computación en la Nube

¿Qué es Computación en la Nube?

La computación en la nube es un modelo que permite el acceso bajo demanda a recursos informáticos como servidores, almacenamiento, bases de datos, software y servicios a través de Internet, sin necesidad de tener infraestructura física propia.

Modelos de Despliegue en la Nube

1. Nube Pública

Descripción: Recursos y servicios proporcionados por un proveedor externo (AWS, Azure, Google Cloud), accesibles para múltiples usuarios a través de Internet.

Ejemplo: Una empresa puede usar servicios de almacenamiento en la nube pública para ampliar rápidamente su capacidad sin invertir en hardware físico.

2. Nube Privada

Descripción: Infraestructura exclusiva para una sola organización, alojada internamente o gestionada por terceros, con mayor seguridad y personalización.

Ejemplo: Un banco puede operar su propia nube privada para proteger los datos de sus clientes.

3. Nube Híbrida

Descripción: Combinación de nube pública y privada para usar cada una según las necesidades.

Ejemplo: Una empresa manufacturera puede usar su nube privada para ERP y la pública para análisis de big data.

4. Multicloud (Multinube)

Descripción: Uso de múltiples nubes de distintos proveedores, evitando la dependencia de uno solo.

Ejemplo: Una empresa usa AWS para almacenamiento, Google Cloud para análisis de datos y Azure para servicios empresariales.

5. Nube Comunitaria

Descripción: Infraestructura compartida por varias organizaciones con intereses comunes (por ejemplo, entidades gubernamentales).
